# 🎮 Simon Game – Memory Challenge

A fun and interactive Simon Says memory game built using **HTML, CSS, and JavaScript**. Test your memory skills by repeating an increasingly complex sequence of colors and sounds. As the levels progress, the challenge becomes more difficult, making it a great way to improve concentration and pattern recognition. Inspired by the classic Simon electronic memory game.

## ✨ Features

* 🎨 Interactive color buttons
* 🔊 Sound effects for each button
* 📈 Progressive difficulty levels
* 🧠 Memory-training gameplay
* ⚡ Instant feedback for correct and incorrect moves
* 🔄 Restart and replay functionality
* 📱 Responsive design for desktop and mobile
* 🎯 Score and level tracking

---

## 🎮 How to Play

1. Press any key to start the game.
2. Watch the sequence of flashing colors.
3. Repeat the exact sequence by clicking the colored buttons.
4. Each level adds a new color to the sequence.
5. Continue repeating the growing pattern.
6. The game ends when you click the wrong color.
7. Try to beat your highest level!
